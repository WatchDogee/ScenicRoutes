# Cache Clear Instructions

After code changes, if UI doesn't update:

1. **Hard Refresh Browser:**
   - Windows: `Ctrl + Shift + R` or `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

2. **Clear Browser Cache:**
   - Open DevTools (F12)
   - Right-click refresh button → "Empty Cache and Hard Reload"

3. **If still not working:**
   - Close browser completely
   - Restart Vite dev server
   - Clear Laravel caches (already done)

The round trip toggle is now at the TOP of the route planner (before saved roads).
Undo/Redo buttons have been removed from RoutePlanner.jsx.
